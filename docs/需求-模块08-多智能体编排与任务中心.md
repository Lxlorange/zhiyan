# 需求-模块08-多智能体编排与任务中心

## 1. 模块定位

多智能体编排与任务中心负责将平台中的复杂学习流程拆解为多个专业 Agent 协作完成。它是系统区别于普通聊天机器人的关键。

## 2. 设计目标

- 明确每个 Agent 的职责。
- 支持 Agent 顺序执行、并行执行和条件执行。
- 支持任务状态展示。
- 支持错误重试。
- 支持结果校验。
- 支持 Agent 轨迹可视化。
- 支持后台预生成任务。

## 3. Agent 列表

### 3.1 DirectionAgent

职责：

- 理解用户科研方向。
- 标准化方向名称。
- 判断目标类型。
- 提出澄清问题。

### 3.2 ProfileAgent

职责：

- 从对话和行为中抽取画像条目。
- 生成画像版本。
- 更新画像置信度。

### 3.3 SyllabusAgent

职责：

- 生成学习清单。
- 拆解知识点。
- 绑定课程资料。

### 3.4 PlannerAgent

职责：

- 生成每日计划。
- 安排学习顺序。
- 调整学习负载。

### 3.5 ClassroomAgent

职责：

- 生成课堂主线。
- 决定课堂内容结构。
- 管理课堂上下文。

### 3.6 ExplanationAgent

职责：

- 生成基础讲解。
- 生成概念卡片。
- 根据画像调整表达方式。

### 3.7 VisualizationAgent

职责：

- 生成 Mermaid 图。
- 生成可视化说明。
- 生成可视化代码。

### 3.8 ExerciseAgent

职责：

- 生成例题。
- 生成互动提问。
- 判定客观题。

### 3.9 DemoAgent

职责：

- 生成复现 demo。
- 生成代码骨架。
- 生成运行步骤。

### 3.10 PaperAgent

职责：

- 解析论文。
- 生成精读笔记。
- 管理文献知识。

### 3.11 WritingAgent

职责：

- 论文润色。
- 报告修改。
- 综述写作。

### 3.12 EvaluationAgent

职责：

- 评估学习效果。
- 分析错因。
- 生成掌握度变化。

### 3.13 MemoryAgent

职责：

- 写回画像。
- 写回学习记录。
- 更新个人知识库。

### 3.14 SafetyAgent

职责：

- 检查来源。
- 检查幻觉。
- 检查作业边界。
- 检查敏感内容。
- 检查是否编造引用。

## 4. Agent 任务字段

每个 Agent 任务应记录：

- 任务 ID。
- 所属流程 ID。
- Agent 名称。
- 输入摘要。
- 输入数据。
- 输出摘要。
- 输出数据。
- 状态。
- 耗时。
- 错误信息。
- 重试次数。
- 使用模型。
- 使用知识库来源。
- 创建时间。
- 完成时间。

## 5. 任务状态

- pending。
- running。
- done。
- failed。
- skipped。
- waiting_user。
- waiting_review。

## 6. 编排流程

### 6.1 方向学习流程

```text
DirectionAgent
-> ProfileAgent
-> SyllabusAgent
-> PlannerAgent
-> SafetyAgent
```

### 6.2 AI 课堂流程

```text
ClassroomAgent
-> ExplanationAgent
-> VisualizationAgent
-> ExerciseAgent
-> DemoAgent
-> SafetyAgent
-> MemoryAgent
```

### 6.3 每日计划流程

```text
PlannerAgent
-> PreGenerateAgent
-> SafetyAgent
```

### 6.4 科研工具流程

```text
PaperAgent / WritingAgent / CitationAgent
-> SafetyAgent
-> KnowledgeBaseAgent
```

## 7. 前端展示

前端应展示 Agent 执行轨迹：

- 当前执行到哪个 Agent。
- 每个 Agent 的状态。
- 每个 Agent 的输出摘要。
- 失败 Agent 的错误信息。
- 是否可重试。
- 是否需要用户确认。

不应只显示“加载中”，应显示具体进度：

```text
DirectionAgent 正在识别方向
SyllabusAgent 已生成 12 个学习项
SafetyAgent 正在检查来源
```

## 8. 错误处理

Agent 失败时应：

- 返回结构化错误。
- 前端弹窗显示状态码和错误信息。
- 保存失败任务记录。
- 支持重试。
- 支持跳过非关键 Agent。
- 支持降级生成。

## 9. 并行与预生成

可以并行执行：

- 多个课堂资源生成。
- 多个学习项预生成。
- 文献解析和笔记生成。
- 可视化和例题生成。

需要控制：

- 并发数量。
- 超时时间。
- 重试次数。
- 用户取消。

## 10. 验收标准

- 每个复杂流程都有 Agent 轨迹。
- Agent 输出结构化保存。
- 前端能看到执行进度。
- 失败时能显示错误并支持重试。
- 后台预生成任务能复用 Agent 编排。
