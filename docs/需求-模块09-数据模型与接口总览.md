## 3. 核心接口

### 3.1 方向探索

- `POST /api/directions/analyze`
- `POST /api/directions`
- `GET /api/directions`
- `GET /api/directions/{id}`
- `PATCH /api/directions/{id}`

### 3.2 学习项目

- `POST /api/learning-projects`
- `GET /api/learning-projects`
- `GET /api/learning-projects/{id}`
- `PATCH /api/learning-projects/{id}`
- `POST /api/learning-projects/{id}/archive`

### 3.3 学习清单

- `POST /api/learning-projects/{id}/syllabus/generate`
- `GET /api/learning-projects/{id}/syllabus`
- `PATCH /api/learning-items/{id}`
- `POST /api/learning-items/{id}/split`
- `POST /api/learning-items/{id}/regenerate`
- `POST /api/syllabus-versions/{id}/activate`

### 3.4 AI 课堂

- `POST /api/classrooms`
- `GET /api/classrooms/{id}`
- `POST /api/classrooms/{id}/messages`
- `POST /api/classrooms/{id}/resources/generate`
- `POST /api/classrooms/{id}/finish`
- `GET /api/classrooms/{id}/notes`

### 3.5 每日计划

- `POST /api/daily-plans/generate`
- `GET /api/daily-plans/today`
- `GET /api/daily-plans`
- `PATCH /api/daily-plan-items/{id}`
- `POST /api/daily-plan-items/{id}/delay`
- `POST /api/daily-plans/{id}/replan`

### 3.6 科研工具

- `POST /api/research-tools/paper/read`
- `POST /api/research-tools/paper/polish`
- `POST /api/research-tools/citation/format`
- `POST /api/research-tools/review/outline`
- `POST /api/research-tools/report/check`

### 3.7 文献知识库

- `POST /api/papers`
- `GET /api/papers`
- `GET /api/papers/{id}`
- `POST /api/papers/{id}/notes`
- `POST /api/knowledge-base/search`
- `POST /api/knowledge-base/chunks`

### 3.8 画像条目

- `GET /api/profile/entries`
- `POST /api/profile/entries`
- `PATCH /api/profile/entries/{id}`
- `POST /api/profile/entries/{id}/disable`
- `GET /api/profile/versions`

### 3.9 Agent 任务

- `GET /api/agent-tasks`
- `GET /api/agent-tasks/{id}`
- `POST /api/agent-tasks/{id}/retry`
- `GET /api/flows/{id}/trace`

## 4. 接口通用要求

- 所有写接口必须鉴权。
- 所有 AI 调用错误必须返回结构化错误。
- 前端必须弹窗展示任意 API 错误。
- 所有生成结果必须保存 Agent 任务记录。
- 所有资源必须尽量带来源。
- 所有用户可编辑对象必须保留更新时间。
