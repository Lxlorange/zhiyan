# 需求-模块07-完整课程知识库与文档集建设

## 1. 模块定位

A3 赛题要求构造至少一门完整高校专业课程的初始知识库或文档集作为系统输入。本模块定义课程知识库建设方式，用于支撑学习清单、AI 课堂、科研工具、多智能体生成和防幻觉。

## 2. 推荐课程

课程名称：

```text
人工智能与 AI4S 实践
```

课程定位：

- 面向计算机、人工智能、电子信息、自动化等专业本科生。
- 连接人工智能基础、数据处理、实验复现和 AI4S 科研入门。
- 以 WiFi CSI 跌倒检测作为贯穿案例之一。

## 3. 课程章节

建议构造 8 个章节：

1. 人工智能与 AI4S 概论。
2. Python 数据处理基础。
3. 机器学习分类任务。
4. 深度学习基础。
5. 信号处理与无线感知入门。
6. WiFi CSI 跌倒检测案例。
7. 实验评价指标与结果分析。
8. 课程项目报告与展示规范。

## 4. 每章资料要求

每个章节至少包含：

- 章节介绍。
- 学习目标。
- 知识点列表。
- 讲义文本。
- 关键概念。
- 典型例题。
- 练习题。
- 实验或案例。
- 拓展阅读。
- 常见误区。
- 课堂讨论问题。
- 评价标准。

## 7. 知识点设计

知识点字段：

- 知识点 ID。
- 名称。
- 所属章节。
- 描述。
- 前置知识。
- 后续知识。
- 难度。
- 标签。
- 典型误区。
- 相关实验。
- 相关练习。

示例知识点：

- 混淆矩阵。
- 准确率。
- 召回率。
- F1 值。
- 类别不平衡。
- 数据集划分。
- Python 指标计算。
- CSI 振幅。
- CSI 相位。
- 人体活动识别。
- 跌倒检测实验设计。
- 实验报告规范。

## 8. 文档切片

导入知识库时，应将文档切成 chunk。

每个 chunk 包含：

- chunk ID。
- 文档 ID。
- 所属章节。
- 关联知识点。
- chunk 内容。
- 关键词。
- 来源。
- 页码或段落号。
- 是否可用于生成。
- 是否需要教师审核。

## 9. 练习题库

题库字段：

- 题目 ID。
- 题型。
- 题干。
- 选项。
- 答案。
- 解析。
- 关联知识点。
- 难度。
- 错因标签。
- 适用画像。

题型包括：

- 单选。
- 多选。
- 判断。
- 简答。
- 代码填空。
- 实验设计。
- 论文理解。

## 10. 实验案例库

实验案例包括：

- 实验目标。
- 数据说明。
- 环境要求。
- 代码结构。
- 运行步骤。
- 预期输出。
- 可视化结果。
- 常见错误。
- 报告要求。
- 拓展任务。

示例：

- 混淆矩阵与评价指标 Python demo。
- WiFi CSI 数据预处理 demo。
- 跌倒检测分类 pipeline demo。
- 实验结果可视化 demo。

## 11. 导入流程

系统应提供课程知识库导入流程：

1. 读取 `course.json`。
2. 创建课程记录。
3. 创建章节记录。
4. 创建知识点记录。
5. 导入 Markdown 文档。
6. 文档切片。
7. 建立 chunk 与知识点关联。
8. 导入题库。
9. 导入实验案例。
10. 导入拓展阅读。
11. 生成检索索引。
12. 输出导入报告。

## 12. 防幻觉使用方式

所有 AI 生成内容应优先检索课程知识库。

生成结果必须包含：

- 使用的知识点。
- 使用的文档。
- 来源片段。
- 置信度。
- 是否需要教师确认。

如果知识库没有相关资料，系统应提示：

```text
当前课程知识库未覆盖该内容，以下为模型推理建议，需要教师确认。
```

## 13. 教师维护能力

教师或课程管理员应能：

- 上传课程资料。
- 编辑知识点。
- 编辑文档切片。
- 审核 AI 生成资源。
- 标记高质量资源。
- 删除错误资料。
- 查看知识库覆盖率。
- 查看高频检索知识点。

## 14. 验收标准

- 至少完成一门课程 8 个章节的结构化知识库。
- 每章有讲义、知识点、练习和案例资料。
- AI 课堂和资源生成能引用课程知识库。
- 搜索接口能返回来源片段。
- 生成内容能展示来源和防幻觉提示。
