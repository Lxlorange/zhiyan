# 需求-模块02-个性化学习清单与路径规划

## 1. 模块定位

学习清单与路径规划模块负责把一个科研方向拆解成用户可执行的学习项。它是从“我想学某个方向”到“我今天具体学什么”的桥梁。

清单不是普通目录，也不是固定课程章节，而是结合用户画像、课程知识库、目标产出、时间周期和学习反馈动态生成的个性化学习路径。

## 2. 核心目标

- 为科研方向生成完整学习清单。
- 支持用户调整、保存和版本管理。
- 支持将学习清单拆成每日计划。
- 支持学习过程中动态插入补救项、拓展项和实践项。
- 支持解释每个学习项为什么推荐给当前用户。

## 3. 学习清单结构

一个学习项目下包含多个学习清单版本，每个版本包含多个学习项。

### 3.1 清单版本字段

- 清单版本 ID。
- 所属学习项目 ID。
- 版本号。
- 生成方式。
- 生成理由。
- 使用的画像版本。
- 使用的知识库版本。
- 用户调整记录。
- 是否当前生效。
- 创建时间。

### 3.2 学习项字段

- 学习项 ID。
- 标题。
- 类型。
- 所属阶段。
- 难度。
- 预计学习时间。
- 推荐理由。
- 学习目标。
- 前置知识。
- 关联知识点。
- 关联课程资料。
- 推荐资源类型。
- 可生成课堂类型。
- 完成标准。
- 评估方式。
- 状态。
- 用户排序。
- 是否锁定。
- 是否用户手动添加。

## 4. 学习项类型

学习项至少支持：

- 概念理解。
- 数学基础。
- 代码实践。
- 实验复现。
- 论文阅读。
- 案例分析。
- 可视化演示。
- 练习评估。
- 项目报告。
- 综述写作。
- 扩展阅读。
- 阶段复盘。

## 5. 路径生成要求

系统生成清单时应考虑：

- 用户当前知识基础。
- 用户学习目标。
- 用户学习节奏。
- 用户资源偏好。
- 当前科研方向难度。
- 课程知识点依赖关系。
- 目标产出所需能力。
- 过往学习记录。
- 练习评估结果。
- 教师要求或课程截止时间。

## 6. 清单生成结果展示

前端应以列表或时间线展示学习清单，每个学习项应显示：

- 标题。
- 类型标签。
- 难度。
- 预计时长。
- 推荐理由。
- 关联知识点。
- 可生成内容类型。
- 完成状态。

用户不应一开始看到大段文字，而应看到可操作清单。

## 7. 用户调整能力

用户应能对学习清单进行调整：

- 拖拽排序。
- 删除学习项。
- 添加自定义学习项。
- 调整难度。
- 调整预计时长。
- 标记暂时跳过。
- 标记需要深入。
- 标记已经掌握。
- 将某一项拆成多个小项。
- 合并相似学习项。
- 重新生成某一阶段。

每次调整都应保存为操作记录。

## 8. 保存与版本管理

用户调整后可以保存学习清单。保存后生成清单版本。

版本管理能力：

- 查看历史版本。
- 对比版本差异。
- 恢复旧版本。
- 复制版本。
- 基于旧版本重新生成。
- 标记当前生效版本。

## 9. 动态路径调整

学习过程中系统应根据行为动态调整路径。

触发条件包括：

- 用户完成课堂。
- 用户答错练习。
- 用户频繁追问某知识点。
- 用户跳过某类资源。
- 用户收藏某类资源。
- 用户调整学习目标。
- 用户延期每日计划。
- 教师添加要求。

调整类型包括：

- 插入补救学习项。
- 插入拓展学习项。
- 调整学习项顺序。
- 降低或提高难度。
- 替换资源类型。
- 增加练习。
- 增加 demo 复现。
- 增加论文阅读。

系统必须解释调整原因。

## 10. 示例清单

方向：WiFi CSI 跌倒检测。

清单示例：

1. WiFi CSI 与无线感知基础。
2. 人体活动识别任务建模。
3. 分类任务与混淆矩阵。
4. 准确率、召回率、F1 值。
5. 类别不平衡与漏检风险。
6. CSI 数据预处理。
7. 跌倒检测模型训练流程。
8. Python 指标计算 demo。
9. 实验结果可视化。
10. 课程项目报告结构。
11. 相关论文精读。
12. 阶段性复盘与答辩问题模拟。

## 11. Agent 设计

### 11.1 SyllabusAgent

负责生成学习清单。

输入：

- 科研方向。
- 学习项目目标。
- 用户画像条目。
- 课程知识库。
- 知识点依赖图。

输出：

- 学习清单。
- 推荐理由。
- 依赖关系。
- 可生成资源类型。

### 11.2 PathPlannerAgent

负责生成学习顺序和阶段。

输出：

- 阶段划分。
- 学习顺序。
- 每阶段目标。
- 完成标准。

### 11.3 AdaptationAgent

负责根据学习行为调整路径。

输出：

- 调整后的清单。
- 调整原因。
- 影响范围。
- 是否需要用户确认。

## 12. 验收标准

- 用户输入一个科研方向后，系统能生成结构化学习清单。
- 清单中每个学习项都有推荐理由和关联知识点。
- 用户可以编辑、保存和恢复清单版本。
- 清单能被拆分为每日计划。
- 学习反馈能触发路径调整。
- 调整过程有可解释说明。
