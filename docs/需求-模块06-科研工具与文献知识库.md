# 需求-模块06-科研工具与文献知识库

## 1. 模块定位

科研工具与文献知识库模块为用户提供科研学习中的辅助能力，包括论文阅读、论文修改、格式规范、引用管理、综述写作、实验报告检查和个人知识库构建。

该模块是主学习流程的补充，但能显著提升平台与普通学习助手的差异。

## 2. 核心目标

- 支持用户围绕当前科研方向管理文献。
- 支持论文阅读和笔记。
- 支持综述写作。
- 支持论文和报告修改。
- 支持引用格式规范。
- 支持构建个人知识库。
- 支持将文献内容用于 AI 课堂和学习清单生成。

## 3. 科研工具列表

### 3.1 论文精读助手

输入：

- 论文标题。
- 摘要。
- 正文片段。
- PDF 文档。
- 用户问题。

输出：

- 研究问题。
- 方法概述。
- 数据集。
- 实验设计。
- 主要结论。
- 创新点。
- 局限性。
- 与当前学习项目的关系。
- 推荐阅读顺序。

### 3.2 论文修改助手

能力：

- 语句润色。
- 学术表达改写。
- 逻辑连贯性检查。
- 段落结构优化。
- 摘要修改。
- 引言修改。
- 实验描述修改。
- 结论边界检查。

要求：

- 不编造实验结果。
- 不替用户虚构引用。
- 必须保留用户原意。
- 标注修改理由。

### 3.3 格式规范助手

支持：

- 论文格式检查。
- 课程报告格式检查。
- 标题层级检查。
- 图表编号检查。
- 公式编号检查。
- 参考文献格式检查。
- 摘要关键词检查。

### 3.4 引用助手

能力：

- BibTeX 生成。
- GB/T 7714 格式。
- APA 格式。
- IEEE 格式。
- 引用缺失提醒。
- 引用与正文匹配检查。
- 文献去重。

### 3.5 综述写作助手

能力：

- 综述选题拆解。
- 文献分类。
- 研究脉络梳理。
- 方法对比表。
- 发展趋势总结。
- 挑战与展望。
- 综述大纲生成。
- 章节草稿建议。

### 3.6 实验报告检查助手

能力：

- 检查实验背景。
- 检查数据来源。
- 检查方法描述。
- 检查评价指标。
- 检查对比实验。
- 检查局限性。
- 检查结果是否过度结论化。

## 4. 文献管理

文献条目字段：

- 文献 ID。
- 标题。
- 作者。
- 年份。
- 会议或期刊。
- DOI。
- URL。
- BibTeX。
- 摘要。
- 关键词。
- 所属项目。
- 阅读状态。
- 用户评分。
- 标签。
- 上传文件路径。
- 创建时间。

阅读状态：

- 未读。
- 粗读。
- 精读中。
- 已精读。
- 已引用。
- 已归档。

## 5. 文献笔记

笔记字段：

- 笔记 ID。
- 文献 ID。
- 用户 ID。
- 笔记类型。
- 内容。
- 引用页码。
- 关联知识点。
- 是否进入知识库。
- 创建时间。

笔记类型：

- 摘要。
- 方法。
- 实验。
- 创新点。
- 局限性。
- 可复现点。
- 可引用观点。
- 个人疑问。

## 6. 个人知识库

用户可将以下内容加入个人知识库：

- 文献摘要。
- 精读笔记。
- 课堂笔记。
- 生成的 demo。
- 学习清单。
- 用户上传资料。
- 科研工具输出。

知识库应支持：

- 检索。
- 标签。
- 关联项目。
- 关联知识点。
- 引用来源。
- 版本管理。
- 用于后续 AI 课堂生成。

## 7. 与主学习流程关系

- 学习项目可绑定文献集合。
- AI 课堂可引用用户文献库。
- 学习清单可插入论文阅读任务。
- 每日计划可安排文献精读。
- 画像模块可记录用户文献阅读能力。
- 科研工具输出可沉淀为知识库内容。

## 8. Agent 设计

- PaperAgent：论文结构化解析。
- WritingAgent：论文修改与学术表达优化。
- CitationAgent：引用格式和参考文献管理。
- ReviewAgent：综述写作辅助。
- KnowledgeBaseAgent：个人知识库构建。
- IntegrityAgent：检查是否编造引用或实验结果。

## 9. 验收标准

- 用户能上传或录入文献信息。
- 用户能生成论文精读结果。
- 用户能进行论文段落修改。
- 用户能生成引用格式。
- 用户能生成综述大纲。
- 文献和笔记能进入个人知识库。
