# 智研星链 A3 云服务器部署说明

本文档面向 Ubuntu 24.04 ECS，采用 Docker Compose + Caddy + PostgreSQL(pgvector) 部署。

## 1. 推荐服务器配置

- CPU/内存：2 vCPU / 4 GiB 可用于小流量演示。
- 系统盘：建议 80 GiB。40 GiB 可以启动，但知识库文件、Docker 镜像、PostgreSQL、生成课件会较快占满。
- 公网带宽：2 Mbps 可用于低频访问；多人下载 PPT 或上传课件时建议升到 5 Mbps。
- 安全组：无域名时只开放 22、80。不要开放 5432、18000、5173。

## 2. 安全组规则

```text
22/tcp   你的固定公网 IP/32
80/tcp   0.0.0.0/0
```

如果暂时不知道本机公网 IP，可以先开放 22 到你的办公网络出口，部署完成后再收紧。

## 3. 访问地址

如果没有域名，直接使用：

```text
http://ECS公网IP
```

`.env.production` 中保持：

```env
APP_SITE_ADDRESS=:80
CORS_ORIGINS=http://ECS公网IP
```

如果后续购买域名，再把域名 A 记录指向 ECS 公网 IP，并将 `APP_SITE_ADDRESS` 改成域名，例如 `a3.example.com`。此时再开放 443，Caddy 会自动申请 HTTPS 证书。

## 4. 服务器初始化

```bash
sudo apt update
sudo apt -y upgrade
sudo timedatectl set-timezone Asia/Shanghai

sudo apt install -y ca-certificates curl git ufw htop unzip
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw --force enable
```

2 vCPU / 4 GiB 建议加 2 GiB swap：

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

## 5. 安装 Docker

```bash
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo ${UBUNTU_CODENAME:-$VERSION_CODENAME}) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker $USER
```

执行完 `usermod` 后重新登录 SSH，让 docker 用户组生效。

## 6. 拉取项目

```bash
sudo mkdir -p /opt/zhiyan-a3
sudo chown -R $USER:$USER /opt/zhiyan-a3
cd /opt/zhiyan-a3
git clone <你的仓库地址> .
```

## 7. 配置生产环境变量

```bash
cd /opt/zhiyan-a3
cp .env.production.example .env.production
nano .env.production
```

必须修改：

```env
APP_SITE_ADDRESS=:80
POSTGRES_PASSWORD=强随机密码
JWT_SECRET_KEY=强随机字符串
CORS_ORIGINS=http://ECS公网IP
QWEN_API_KEY=你的千问 API Key
QWEN_BASE_URL=https://ws-zdgnhxh8fif3r56e.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
```

生成随机密钥：

```bash
openssl rand -hex 32
```

## 8. 首次启动

```bash
cd /opt/zhiyan-a3
docker compose -f docker-compose.prod.yml --env-file .env.production build backend
docker compose -f docker-compose.prod.yml --env-file .env.production build frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d
```

查看状态：

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production ps
```

查看后端日志：

```bash
docker logs -f zhiyan-a3-backend
```

查看 HTTPS / Caddy 日志：

```bash
docker logs -f zhiyan-a3-caddy
```

访问：

```text
http://ECS公网IP
```

## 10. GitHub Actions 自动部署

仓库已包含 `.github/workflows/deploy.yml`。

在 GitHub 仓库 `Settings -> Secrets and variables -> Actions` 中添加：

```text
SERVER_HOST=服务器公网 IP
SERVER_USER=部署用户，例如 ubuntu 或 root
SERVER_PORT=22
SERVER_SSH_KEY=私钥内容
```

服务器上需要提前完成：

```bash
cd /opt/zhiyan-a3
git remote -v
docker compose version
```

之后推送到 `master` 分支会自动执行：

```bash
git pull --ff-only origin master
docker compose -f docker-compose.prod.yml --env-file .env.production build backend
docker compose -f docker-compose.prod.yml --env-file .env.production build frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d
docker image prune -f
```

## 11. 数据持久化

当前持久化卷：

- `postgres_data`：PostgreSQL 数据库。
- `backend_generated`：生成的 PPT、HTML、语音稿等。
- `backend_uploads`：知识库上传文件。
- `caddy_data`：HTTPS 证书。
- `caddy_config`：Caddy 运行配置。

不要用 `docker compose down -v`，这会删除数据库和上传文件。

## 12. 备份

数据库备份：

```bash
docker exec zhiyan-a3-postgres pg_dump -U zhiyan zhiyan_a3 > zhiyan_a3_$(date +%F).sql
```

上传和生成文件备份：

```bash
docker run --rm -v zhiyan-a3_backend_uploads:/data -v "$PWD":/backup alpine tar czf /backup/backend_uploads_$(date +%F).tar.gz -C /data .
docker run --rm -v zhiyan-a3_backend_generated:/data -v "$PWD":/backup alpine tar czf /backup/backend_generated_$(date +%F).tar.gz -C /data .
```

## 13. 常见问题

### Caddy 无法访问

检查：

```bash
docker logs zhiyan-a3-caddy
```

常见原因：

- 安全组没有开放 80。
- 服务器系统防火墙没有开放 80。
- `.env.production` 的 `APP_SITE_ADDRESS` 不是 `:80`。

如果后续改成域名 HTTPS，再检查域名 A 记录、443 安全组和 Caddy 证书日志。

### 后端启动失败，提示 pgvector

本项目生产 Compose 使用 `pgvector/pgvector:pg16`，正常会内置 vector 扩展。若仍失败，查看：

```bash
docker logs zhiyan-a3-postgres
docker logs zhiyan-a3-backend
```

### 上传大文件失败

当前 Caddy 和 Nginx 均设置为 350 MB。若还失败，检查浏览器报错和：

```bash
docker logs zhiyan-a3-caddy
docker logs zhiyan-a3-backend
```

### 内存不足

先确认 swap：

```bash
free -h
```

构建时内存紧张可临时停止旧容器后再构建：

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production stop frontend backend
docker compose -f docker-compose.prod.yml --env-file .env.production build frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d
```

前端 Dockerfile 已设置：

```text
NODE_OPTIONS=--max-old-space-size=2048
```

如果仍然出现 `JavaScript heap out of memory`，先确认服务器已经开启 swap；仍失败则把 ECS 临时升到 8 GiB 内存完成构建，或在本地/CI 构建镜像后推送镜像仓库。

### 后端 apt-get 阶段很慢

后端镜像默认不安装 `fonts-noto-cjk`，避免小带宽服务器在 50MB+ 字体包下载阶段超时。若你确实需要容器内 LibreOffice 使用完整 Noto CJK 字体渲染中文 PPT/PDF，在 `.env.production` 中加入：

```env
INSTALL_CJK_FONTS=true
```

然后重新构建 backend。默认值为 `false`，不影响 Tesseract 中文 OCR 语言包 `tesseract-ocr-chi-sim`。

后端镜像已改为使用阿里云 Debian / PyPI 源，并收窄 LibreOffice 安装范围。如果服务器上旧构建已经卡住，需要先中断当前构建，拉取最新代码后重新构建：

```bash
cd /opt/zhiyan-a3/A3
git pull --ff-only
docker compose -f docker-compose.prod.yml --env-file .env.production build backend
```

如果仍然很慢，优先检查服务器访问软件源是否正常：

```bash
curl -I https://mirrors.aliyun.com/debian/
curl -I https://mirrors.aliyun.com/pypi/simple/
```
