# 用户操作与预期返回

本文档用于检查 A3 项目核心链路是否按需求实现。写法参考“需求实现检查”类 prompt 的思路：先列需求点，再给操作步骤、预期页面结果和预期接口返回字段。

## 1. 启动方式

本项目使用 PostgreSQL，不再使用 SQLite。先准备数据库：

```sql
CREATE DATABASE zhiyan_a3;
CREATE USER zhiyan WITH PASSWORD 'zhiyan';
GRANT ALL PRIVILEGES ON DATABASE zhiyan_a3 TO zhiyan;
\c zhiyan_a3
GRANT ALL ON SCHEMA public TO zhiyan;
```

复制环境变量模板：

```powershell
cd D:\Code\rjb\A3
Copy-Item backend\.env.example backend\.env
```

确认 `backend\.env` 中数据库连接为：

```text
DATABASE_URL=postgresql+psycopg://zhiyan:zhiyan@localhost:5432/zhiyan_a3
```

在项目根目录执行：

```powershell
cd D:\Code\rjb\A3
python -m venv backend\.venv
.\backend\.venv\Scripts\Activate.ps1
pip install -r backend\requirements.txt
python run.py
```

或进入后端目录执行：

```powershell
cd D:\Code\rjb\A3\backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
```

启动后访问：

- 项目首页：`http://127.0.0.1:8000`
- API 文档：`http://127.0.0.1:8000/docs`

## 2. 需求实现对照

| A3 需求点 | 当前实现 | 代码位置 |
| --- | --- | --- |
| 对话式学习画像 | 输入学生自然语言描述，生成知识基础、目标、认知风格、短板、实践能力、资源偏好等画像 | `backend/app/services/learning_workflow.py:create_profile` |
| 知识短板诊断 | 根据画像生成混淆矩阵、数据集划分、CSI 特征等短板 | `diagnose_gaps` |
| 个性化学习路径 | 生成评价指标、CSI 理解、代码实操、项目报告 4 步路径 | `plan_path` |
| 多智能体资源生成 | 生成讲义、思维导图、练习题、论文导读、代码案例、视频脚本、项目材料 7 类资源 | `generate_resources` |
| 智能辅导 | 针对召回率问题生成带来源、策略和追问练习的辅导结果 | `tutor_answer` |
| 学习效果评估 | 提交练习后计算得分、判断错题、更新画像和学习路径 | `assess_answers` |
| 画像动态更新 | 评估后 `profile.revision` 增加，`weak_points` 和 `mastery` 更新 | `assess_answers` |
| 教师驾驶舱 | 生成活跃会话、知识点、资源类型、短板分布和教学建议 | `build_teacher_dashboard` |
| 一个命令起前后端 | FastAPI 直接托管 `/` 页面和 `/api/*` 接口 | `backend/app/main.py`, `backend/app/web/*` |
| 登录注册 | PostgreSQL 用户表、bcrypt 密码哈希、JWT Bearer Token | `backend/app/api/routes_auth.py`, `backend/app/models/user.py` |

## 3. 操作步骤与预期页面结果

### 3.1 注册或登录

操作：

1. 打开 `http://127.0.0.1:8000`。
2. 在“注册”面板保留默认值或填写：

```text
用户名: student01
邮箱: student01@example.com
姓名: 演示学生
角色: 学生
密码: password123
```

3. 点击“注册并登录”。
4. 如果已经注册过，则在“登录”面板输入用户名和密码，点击“登录”。

预期页面结果：

- 右上角从“未登录”变为“演示学生 / student”。
- 浏览器 localStorage 保存 `access_token` 和 `current_user`。
- 后续点击“运行完整链路”时，请求会自动携带 `Authorization: Bearer <token>`。

预期接口：

```http
POST /api/auth/register
```

请求：

```json
{
  "username": "student01",
  "email": "student01@example.com",
  "full_name": "演示学生",
  "role": "student",
  "password": "password123"
}
```

返回关键字段：

```json
{
  "access_token": "...",
  "token_type": "bearer",
  "user": {
    "id": 1,
    "username": "student01",
    "email": "student01@example.com",
    "full_name": "演示学生",
    "role": "student",
    "is_active": true
  }
}
```

重复注册同名用户时，预期返回 `409`。

登录接口：

```http
POST /api/auth/login
```

请求：

```json
{
  "username": "student01",
  "password": "password123"
}
```

返回字段同注册接口。

当前用户接口：

```http
GET /api/auth/me
Authorization: Bearer <access_token>
```

返回当前用户信息。

### 3.2 运行完整链路

操作：

1. 确保已经登录。
2. 保留默认学生描述，或输入：

```text
我是计算机专业大二学生，Python 基础一般，想做 WiFi CSI 跌倒检测课程项目，但不太理解召回率、混淆矩阵和数据集划分。
```

3. 点击“运行完整链路”。

预期页面结果：

- 顶部指标出现 Session 短 ID。
- 画像版本显示 `v1`。
- 短板数量显示 `3`。
- 资源数量显示 `7`。
- “学习画像”区域展示知识基础、学习目标、认知风格、实践能力、资源偏好、学习节奏、兴趣方向、当前短板。
- “知识短板诊断”区域展示 3 个短板：混淆矩阵、数据集划分、CSI 特征。
- “个性化学习路径”展示 4 个步骤。
- “多 Agent 资源生成”展示 7 张资源卡片。
- “智能体协作轨迹”包含 ProfileAgent、DiagnoseAgent、PathPlannerAgent、ResourceAgentGroup、QuizAgent、SafetyCheckAgent。
- “教师驾驶舱”展示指标、短板分布和教学建议。

预期接口：

```http
POST /api/workflow/start
Authorization: Bearer <access_token>
```

请求：

```json
{
  "message": "我是计算机专业大二学生，Python 基础一般，想做 WiFi CSI 跌倒检测课程项目，但不太理解召回率、混淆矩阵和数据集划分。"
}
```

返回关键字段：

```json
{
  "session_id": "...",
  "profile": {
    "revision": 1,
    "weak_points": ["混淆矩阵", "召回率与准确率", "数据集划分", "CSI 特征理解"]
  },
  "gaps": [],
  "path": [],
  "resources": [],
  "quiz": [],
  "agent_trace": []
}
```

其中 `gaps` 应有 3 项，`path` 应有 4 项，`resources` 应有 7 项，`quiz` 应有 3 项。

未登录调用时，预期返回 `401 not authenticated`。

### 3.3 智能辅导

操作：

1. 在“智能辅导”输入框保留默认问题：

```text

```

2. 点击“提问并写入会话”。

预期页面结果：

- 显示辅导回答。
- 显示“策略”。
- 显示“追问练习”。
- 显示来源：`第 7 章 实验评价指标与结果分析`、`第 6 章 WiFi CSI 跌倒检测案例`。
- Agent 轨迹新增 `TutorAgent`。

预期接口：


### 3.4 练习评估与画像更新

操作：

1. 在“练习评估与画像更新”中选择题目答案。
2. 建议选择：
   - 第 1 题：`80%`
   - 第 2 题：`可能掩盖跌倒漏检`
   - 第 3 题：`最终评估泛化能力`
3. 点击“提交练习并更新画像”。

预期页面结果：

- 显示得分。
- 显示更新短板。
- 显示“下一轮学习路径已插入类别不平衡与 F1 值专项补救节点。”
- 顶部画像版本从 `v1` 变成 `v2`。
- 学习路径中新增“补救：类别不平衡与 F1 值专项”。
- Agent 轨迹新增 `AssessmentAgent`。

## 4. 当前边界

- 用户数据已落 PostgreSQL；学习工作流会话仍为内存态，重启服务后会话清空。
- 当前 Agent 是规则化 mock 编排，后续可替换为真实大模型/讯飞星火调用。
- 当前 RAG 来源为课程章节名和资源卡片来源字段，后续可接入向量库和真实课程文档。
- 当前内置前端是原生 HTML/CSS/JS，目的是满足一命令启动；`frontend/` 下的 Vue 工程保留为后续增强方案。
