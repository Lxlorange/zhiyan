# 开源项目与协议引用

## THU-MAIC/OpenMAIC

- 项目名称：OpenMAIC
- 来源：https://github.com/THU-MAIC/OpenMAIC
- 协议：MIT License
- 本项目使用方式：参考其面向 AI 课堂的资源组织思路，将课堂资源拆分为 slides、quizzes、interactive/practice、PBL/reflection，并在本项目中用 FastAPI + Vue 独立实现“PPT 课件生成、例题作答、实操提交、复盘提交、完成闸门校验”链路。
- 说明：当前代码未直接复制 OpenMAIC 前端组件或 Next.js 导出逻辑，而是按本项目架构实现等价功能；PPT 文件由后端 `python-pptx` 生成。

### 课堂互动与可视化演示补充说明

- 参考点：OpenMAIC 的 Deep Interactive Mode、interactive HTML simulations、课堂 slides/quizzes/practice/reflection 组合方式。
- 本项目实现方式：后端 `VisualizationAgent` 只调用大模型生成结构化演示数据，HTML/CSS/Canvas 动画由本项目后端模板渲染，前端 Vue 通过鉴权接口以 blob iframe 方式展示。
- 代码边界：未复制 OpenMAIC 的 Next.js 页面、组件、导出逻辑或动画代码；仅参考其产品功能组织思想，并在本项目 FastAPI + Vue 架构中独立实现。
- 协议遵循：OpenMAIC 为 MIT License，提交文档和代码引用说明中保留项目名称、来源和协议标注。
